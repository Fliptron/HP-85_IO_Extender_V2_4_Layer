# HP-85_IO_Extender_V2_4_Layer
 Extender card for HP Series 80 Computers

This PCB design was created with Altium V21.5.1

It is intended to be manufactured by JLCPCB, but has not yet
actually been manufactured and tested. To reduce risk, I suggest
not using these files until this README has been updated to indicate
that PCBs have been made and tested.

The PCB is intended to be a 4 layer board with layer usage as follows

*  Top Layer (GTL) signals and ground pour
*  Plane Layer (G1) +5V
*  Plane Layer (G2) Ground (GND)
*  Bottom Layer (GBL) signals

JLCPCB settings:
 *  1.6 mm thick
 *  FR4
 *  Green solder mask , white silk/overlay both sides
 *  Surface finish is ENIG
 *  1 um gold thickness. If you expect to be plugging and unplugging the extender a lot, choose 2um gold
 *  1 oz copper for top and bottom layers, 0.5 oz copper for the two inner layers
 *  Chamfer of 30 or 45 degrees. 30 degree is slightly lower insertion force
 *  Leave all other settings at default, unless you want to make specific changes
